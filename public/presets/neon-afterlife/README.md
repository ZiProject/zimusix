# NEON AFTERLIFE — Zimusix preset

Cyberpunk night-drive preset with acid yellow, toxic magenta, electric cyan, dark glass surfaces and a refined audio spectrum.

## Install
1. Extract this ZIP.
2. In Zimusix, open **Themes → Add preset folder**.
3. Select the extracted `neon-afterlife` folder.
4. Choose **NEON AFTERLIFE** → **Use this preset**.

## Spectrum tuning
- Built-in visualizer: `bars`
- Placement: `stage`, `player` (not background, to avoid overpowering lyrics)
- 64 bars, 2 px thickness, smoothing 0.84
- Gradient color mode with restrained cyan/magenta glow
- 148 px stage visualizer height

## Settings
- Neon intensity — CSS variable setting.
- Scanline strength — CSS variable setting.
- Primary neon — theme accent color.
- Bass-reactive effects — valid boolean binding to `background.react`.

This preset contains declarative configuration and CSS only; no JavaScript or HTML.
